# Definition of done

A change is done only when the applicable items below are satisfied.

- [ ] The change maps to one or more requirement IDs or has an explicit scope decision.
- [ ] Acceptance criteria are testable and unchanged unless approved.
- [ ] Implementation and tests are complete for the stated scope.
- [ ] Mandatory tests ran against the final relevant revision.
- [ ] Failures, skips, and inconclusive checks are reported accurately.
- [ ] Independent challenge and scope-drift review were performed where applicable.
- [ ] Security and permission implications were reviewed.
- [ ] Documentation, schemas, examples, and changelog are updated.
- [ ] Known limitations and exceptions are explicit.
- [ ] Report claims are supported by recorded evidence.
- [ ] No unresolved mandatory finding remains for a `verified` status.
